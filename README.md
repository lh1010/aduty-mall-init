# Aduty Mall

1，Aduty Mall 是一款免费开源可商用的 PHP 商城系统源码。

2，基于 Laravel 框架开发，易扩展、高负载、稳定可靠。

3，系统设计思路清晰，代码整洁、注释完善、可读性强，因此可在系统基础上很容易的扩展新功能。

4，提供客户端：电脑PC、手机H5、微信小程序。

5，基于 Apache2.0 开源协议发布，免费且不限制商用。可自由修改，打造专属电商平台。
